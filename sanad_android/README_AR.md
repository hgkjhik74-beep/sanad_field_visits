# تطبيق سند لإدارة الزيارات الميدانية – Android

هذا مشروع Android أصلي بسيط يعرض تطبيق الزيارات المرفق داخل WebView محلي. جميع ملفات التطبيق مضمّنة داخل APK، ولا يحتاج إلى اتصال بالإنترنت أو خادم.

## المزايا
- واجهة عربية واتجاه RTL.
- إضافة الزيارات وتعديلها وحذفها والبحث والتصفية.
- حفظ تلقائي محلي على الجهاز باستخدام LocalStorage.
- تصدير CSV ونسخة JSON احتياطية إلى `Downloads/Sanad`.
- استيراد النسخة الاحتياطية من مدير الملفات.
- لا يطلب صلاحية الإنترنت ولا يعتمد على مكتبات أو خدمات خارجية.

## إنشاء ملف APK
1. افتح مجلد `sanad_android` في Android Studio.
2. انتظر مزامنة Gradle (يحتاج Android Studio إلى تنزيل Android Gradle Plugin وAndroid SDK أول مرة).
3. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. بعد انتهاء البناء ستجد الملف عادة في:
   `app/build/outputs/apk/debug/app-debug.apk`
5. انقل APK إلى هاتف Android وثبّته. قد تحتاج للسماح بالتثبيت من هذا المصدر.

## تنبيه مهم للبيانات
البيانات تحفظ داخل التطبيق على نفس الهاتف. احفظ نسخة JSON دورياً من زر «نسخة احتياطية»، ثم استوردها عند تغيير الهاتف أو إعادة تثبيت التطبيق. حذف التطبيق أو بياناته قد يؤدي إلى فقدان السجلات المحلية.

## متطلبات البناء
- Android Studio حديث.
- Android SDK Platform 35.
- JDK 17.

## بناء APK تلقائياً دون تثبيت Android Studio على الكمبيوتر
أضف مجلد `sanad_android` إلى مستودع GitHub، ثم ارفع الملفات إلى فرع `main` أو `master`. سيبدأ سير العمل الموجود في `.github/workflows/build-apk.yml` ببناء APK تلقائياً. بعد نجاحه:
1. افتح تبويب **Actions** في المستودع.
2. اختر آخر عملية **Build Sanad Android APK**.
3. من قسم **Artifacts** نزّل `sanad-field-visits-debug-apk`.
4. فك ضغط الملف الناتج لتحصل على `app-debug.apk`.

هذه الخطوات تحتاج حساب GitHub واتصال إنترنت لتنفيذ البناء على خوادم GitHub. ملف APK الناتج نسخة Debug للتثبيت والاختبار.
